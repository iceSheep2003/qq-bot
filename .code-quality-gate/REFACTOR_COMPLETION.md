# 本次结构重构完成条件

保持已有群私聊、默认直接 LLM、词注入、可选图谱与双声明式扩展入口的行为。
不在结构重构中实现新的图谱模型、跨场景共享授权或私聊排期业务。

1. 会话服务只协调准入、回合与已声明的动作；成功回执、分段状态与对外记录由单一 delivery 组件处理。
2. 观察存储为显式 Protocol，核心不依赖 SQLite 或具体消费者实现；观察器使用注入日志。
3. 后台工作使用延迟工厂，在 run 内启动；退出先取消并等待全部工作，再反序关闭资源；未启动应用不遗留协程。
4. 平台入站路由从资源组合拆出；启动模块仅组装依赖，平台事件解释有独立入口。
5. 情绪 SQLite 放 infrastructure/storage，核心情绪系统注入仓储；HTTP 向量适配器与环境配置放 infrastructure/adapters，内存检索不自行打开 HTTP 客户端。
6. BotPolicy 只有 contracts 中的一份定义，调用方和测试迁移到 canonical 构造，不保留旧平铺类或旧目录转发。
7. 完整历史测试不减断言，不降低阈值；新边界有先于实现记录的 red，各阶段实际 CQG green 与 gate；最终无未等待协程告警。

阶段顺序：发送/观察契约；运行与启动组合；存储与策略依赖；最后完整核对目录、文档、wheel 和门禁。讲解稿只更新仓库外本地文件，提交只在当前分支，不推送、不部署。
