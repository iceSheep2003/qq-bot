# 当前改造进度

更新日期：2026-10-16。当前代码结构见 [架构说明](../architecture/README.md)。

## 已实现

- 群聊和可选私聊的场景准入、会话 scope 校验与回复流程。
- 群私聊 Skill 可见性、选择和显式加载；覆盖 Owner 声明覆盖后的选择预算。
- 群私聊独立的可选认知通道，默认 LLM；图谱缺失或失败时降级。
- 私聊工具执行权限以及群聊原有流程的回归保护。
- 统一 `src/` 源码，七种职责包、对应测试、分类工具和分层文档。
- 公共契约与五类运行边界的自动检查，真实 wheel 构建安装与资源验证。
- 锁定版本的 Code Quality Gate 测试、迭代审计与最终合并门禁。
- 回复后观察已从会话服务提取，独立管理队列、去重、恢复和关闭。
- 记忆提炼与短期压缩已提取到 ConversationMaintenance，独立管理并发、scope 占用、预算和取消清理；新阶段在实现前记录 CQG red。

## 后续实现顺序

1. 明确跨群私聊记忆授权、用途、撤销和传播规则，再实现共享记忆。
2. 设计新的认知图谱类型、写入和读取契约，按测试替换历史图谱结构。
3. 补充私聊业务 Skill，复用内置工具与既有权限。
4. 为私聊增加声明式定时任务，覆盖目标校验、重启去重、权限和失败回执。
5. 继续收敛会话服务中的发送记账职责、内置功能装配和旧记忆 I/O，补齐观察存储的显式端口。
6. 在真实 NapCat、QQ 及所选模型上完成群私聊联调，再决定上线。

每阶段先写架构与验收，再记录红阶段；通过完整回归和最终门禁后合并。
